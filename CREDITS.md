# Credits

Where every picture, sound and font in this project came from, and what it is
allowed to be used for.

The game's Terms of Use (section 9) already tell players that third-party art,
sounds and fonts "are used under their own licences". This file is where that
promise is backed up.

---

## How to fill this in

Every **❓** is something only the team knows. Replace it with one of these:

| Source | Write it like this |
|---|---|
| A team member made it | `Mark` · `Ivo` · `Emmanuel` |
| An AI tool made it | `AI — <tool name>` (the Terms say some art was AI-made) |
| Downloaded or bought | the site and a link, e.g. `itch.io — <pack name> — <link>` |

Then write the licence: `Own work`, `CC0`, `CC BY 4.0`, `Paid asset licence`,
and so on. If a folder holds files from different places, split its row.

**If you cannot find where something came from, remove it before making the
repo public.**
